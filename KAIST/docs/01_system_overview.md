## 2. 주요 구성요소

### 2.1 비전 시스템 (Python)

| 구성요소 | 설명 |
|----------|------|
| **Intel RealSense** | RGB 카메라 (1920x1080 @ 15fps) |
| **YOLO Model** | 충전건/충전포트 객체 검출 |
| **ChArUco Board** | 로봇-카메라 좌표계 변환용 마커 |
| **Kalman Filter** | 포즈 추정 안정화 |
| **PnP Solver** | 3D 포즈 계산 |

### 2.2 로봇 컨트롤러

| 구성요소 | 설명 |
|----------|------|
| **6축 로봇** | 산업용 로봇 암 |
| **Modbus Server** | TCP 통신 (포트 1502) |
| **Script Engine** | Lua 기반 프로그래밍 |
| **DIO** | 그리퍼 제어용 디지털 I/O |

### 2.3 End Effector

| 구성요소 | 설명 |
|----------|------|
| **그리퍼** | 충전건 파지 장치 |
| **카메라 마운트** | RealSense 카메라 장착부 |

## 3. 통신 구조

```
┌──────────────┐         Modbus TCP          ┌──────────────┐
│    Python    │ ◄─────────────────────────► │    Robot     │
│   (Client)   │    192.168.0.29:1502       │   (Server)   │
└──────────────┘                             └──────────────┘
       │                                            │
       │  Register 351: Command (1,2,3,4)          │
       │  Register 352: Response (0,1,2)           │
       │  Register 301-306: Pose Main              │
       │  Register 307-312: Pose Back              │
       │  Register 158-169: Camera Pose            │
       │                                            │
       ▼                                            ▼
┌──────────────┐                             ┌──────────────┐
│   비전 처리   │                             │   모션 제어   │
│  좌표 계산   │                             │   그리퍼     │
└──────────────┘                             └──────────────┘
```

## 4. 좌표계

### 4.1 좌표계 종류

| 좌표계 | 설명 | 단위 |
|--------|------|------|
| **World** | 로봇 베이스 기준 | mm, degree |
| **Camera** | 카메라 광학 중심 기준 | m, radian |
| **Tool** | 엔드이펙터 기준 | mm, degree |
| **Object** | 대상 물체 기준 | m |

### 4.2 좌표 변환

```
Object (Camera 좌표계)
        │
        ▼ ChArUco Board 변환
World (Robot 좌표계)
        │
        ▼ Toolframe 변환
Tool (End Effector 좌표계)
```
