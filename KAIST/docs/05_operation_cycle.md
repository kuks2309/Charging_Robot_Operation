## 2. 단계별 상세 설명

### 2.1 [1] Rilham_get - 충전 스테이션에서 충전건 픽업

**목적:** 충전 스테이션에 거치된 충전건을 로봇이 집어 올림

**스크립트:** `Rilham_get.prs`

**설정값:**
| 변수 | 값 | 설명 |
|------|-----|------|
| var.i(1) | 1 | task_number |
| var.i(2) | 3 | toolframe |
| var.i(3) | 1 | grip |

**동작 순서:**
```
1. toolframe(3) 설정
2. movep(lp3) - 대기 위치로 이동
3. movel(lp2) - 접근 위치로 이동
4. Vision_task 호출
   ├─ Python: VisionProcessorGun으로 충전건 위치 계산
   ├─ Modbus: 좌표 전송 (301-312)
   └─ Robot: 비전 좌표로 이동
5. Gripper_grip 실행 - 충전건 잡기
6. toolframe(2) 설정
7. movel(lp5) - 복귀 위치로 이동
```

**비전 처리:**
- 대상: 충전건 (Gun)
- 마커: ArUco 마커 기반
- 출력: 6DoF 포즈 (x, y, z, Rx, Ry, Rz)

### 2.2 [2] Car_put - 차량 충전포트에 충전건 삽입

**목적:** 차량의 충전 포트에 충전건을 삽입

**스크립트:** `Car_put.prs`

**설정값:**
| 변수 | 값 | 설명 |
|------|-----|------|
| var.i(1) | 4 | task_number |
| var.i(2) | 2 | toolframe |
| var.i(3) | 2 | ungrip |

**동작 순서:**
```
1. toolframe(2) 설정
2. movep(lp1) - 대기 위치로 이동
3. movep(lp2) - 접근 위치로 이동
4. Vision_task 호출
   ├─ Python: VisionProcessorPort로 충전포트 위치 계산
   ├─ Modbus: 좌표 전송 (301-312)
   └─ Robot: 비전 좌표로 이동 (충전건 삽입)
5. Gripper_ungrip 실행 - 충전건 놓기
6. toolframe(3) 설정
7. movep(lp3) - 복귀 위치로 이동
```

**비전 처리:**
- 대상: 충전포트 (Port)
- 정밀도 요구: 높음 (삽입 동작)
- 오프셋: 삽입 방향으로 접근

### 2.3 [3] Car_get - 차량에서 충전건 분리

**목적:** 충전 완료 후 차량에서 충전건을 분리

**설정값:**

|------|-----|------|
| var.i(1) | 3 | task_number |
| var.i(2) | 3 | toolframe |
| var.i(3) | 1 | grip |

**동작 순서:**
```
1. toolframe(3) 설정
2. movep(lp1) - 대기 위치로 이동
3. movep(lp7) - 접근 위치로 이동
```

## 5. 시뮬레이션 모드

`sim_mode = 1`일 때 비전 시스템 없이 사전 정의된 위치로 이동합니다.

```lua
if sim_mode == 1 then
    toolframe(2)
    if var.i(1) < 3 then
        -- Rilham 작업
        movel(var.p(8))
        movel(var.p(7))
        movel(var.p(6))
    else
        -- Car 작업
        movel(var.p(12))
        movel(var.p(11))
        movel(var.p(10))
    end
end
```

## 6. 에러 처리

```lua
if move_count >= 10 then
```
