# 좌표계 정의 및 변환 관계

## 1. AR Tag 좌표계 (OpenCV ArUco 표준)

**원점:** 마커 중심

```
마커를 정면에서 바라볼 때:

        +Y (↑ 마커 상단)
         │
         │
  ───────●───────→ +X (마커 우측)

  +Z: 마커에서 카메라 방향 (화면 밖으로)
```

**코너 좌표 (OpenCV 공식):**
- corner 0: (-X, +Y) 좌상단
- corner 1: (+X, +Y) 우상단
- corner 2: (+X, -Y) 우하단
- corner 3: (-X, -Y) 좌하단

**출처:** https://docs.opencv.org/4.x/d5/dae/tutorial_aruco_detection.html

---

## 2. Vision 좌표계 (TF1, OpenCV 카메라 표준)

**원점:** 카메라 렌즈 중심

```
카메라 이미지 기준:

  ───────●───────→ +X (이미지 우측)
         │
         │
         ↓ +Y (이미지 하단)

  +Z: 카메라 광축 (카메라 → 물체 방향)
```

---

## 3. 좌표계 비교

| 축 | Vision (TF1) | AR Tag |
|:---:|:---|:---|
| X+ | 이미지 우측 (→) | 마커 우측 (→) |
| Y+ | 이미지 하단 (↓) | 마커 상단 (↑) |
| Z+ | 카메라 → 물체 | 마커 → 카메라 |

---

## 4. 변환 관계

### Vision (TF1) → AR Tag

```
AR_X =  TF1_X
AR_Y = -TF1_Y
AR_Z = -TF1_Z
```

**변환 계수: (1, -1, -1)**

### 변환 행렬

```
R_TF1_to_AR = [ 1   0   0 ]
              [ 0  -1   0 ]
              [ 0   0  -1 ]
```

(X축 기준 180도 회전과 동일)

### 역변환 (AR Tag → Vision)

```
TF1_X =  AR_X
TF1_Y = -AR_Y
TF1_Z = -AR_Z
```

동일한 변환 행렬 적용 (R^2 = I)
